# Project Overview

Algodonales Fresh POS is a checkout (POS) system developed for the Algodonales Fresh supermarket.

The goal is to create a fast, simple and modern system for processing sales, managing products, and generating receipts.

The entire system is designed to work on a **single main screen**, similar to real supermarket POS systems.

---

# Main Features

- Product management
- Shopping cart system
- Payment system
- Receipt generation (tickets)
- Sales history
- Stock control
- Fast product search

---

# Controls

- Left Click: Main actions (select products, press buttons)
- Keyboard: Search and data input
- Esc: Cancel / go back

---

# System Rules

- Fast and simple interface (real cashier usage)
- No complex navigation menus
- Optimized for speed
